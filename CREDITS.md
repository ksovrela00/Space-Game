# Заимствованное

Весь код в проекте свой. Со стороны взяты звук, корпус корабля и детали
станций — всё **CC0** (общественное достояние, атрибуция не обязательна,
но здесь она есть).

| что | источник | лицензия | автор |

| корпус корабля игрока («Challenger») | [LowPoly Spaceships Pack](https://opengameart.org/content/lowpoly-spaceships-pack) | CC0 | Quaternius |
| детали станций (тарелки, генераторы, баки, фермы, турели) | [Space Kit](https://kenney.nl/assets/space-kit) | CC0 | Kenney |
| здания наземного города (кварталы, башни) | [City Kit (Commercial)](https://kenney.nl/assets/city-kit-commercial) | CC0 | Kenney |
| космопорт города (ангары, баки, монорельс, техника) | [Space Kit](https://kenney.nl/assets/space-kit) | CC0 | Kenney |

## Корпус

Модель не лежит в репозитории в исходном виде: движок рисует корабли
плоским затенением и без текстур, поэтому из OBJ и его текстуры один раз
перегоняется то, что движку нужно, — геометрия и цвет НА ГРАНЬ. Результат
лежит в [js/models/hull.data.js](js/models/hull.data.js) (52 КБ чисел) и
собирается заново одной командой:

```
npm run ship               # заново собрать текущий корпус (Challenger)
npm run ship Striker       # поставить другой корабль из пака
node tools/ship.mjs --list # какие есть
node tools/ship.mjs --clean # удалить скачанный пак (98 МБ во временной папке)
```

Конвертер ([tools/ship.mjs](tools/ship.mjs)) сам скачивает пак, приводит
модель к осям игры (нос +Z, верх +Y, центр в нуле), масштабирует до
принятых 65 метров, снимает цвет каждой грани усреднением текстуры по её
UV-развёртке и находит точки факелов и стоек шасси. Что получилось, он
показывает силуэтом прямо в консоли — этого хватает, чтобы убедиться, что
корабль не встал задом наперёд.

Смена корабля меняет и физику посадки: просветы под днищем
(`SHIP.gearClear`, `SHIP.hullClear`) и зазор в створе порта считаются от
обводов корпуса, а не заданы числами. Проверки в `tools/test.mjs`
(раздел «корпус») следят, что всё сходится: нос смотрит вперёд, сопла в
корме, стойки под днищем, корабль пролезает в порт.

Процедурный клин, с которого всё начиналось, никуда не делся —
`buildWedge()` в [js/models/ships.js](js/models/ships.js). По нему видно,
каких обводов ждёт остальной код, и он же запасной вариант, если данных
корпуса нет.

## Растительность

Деревья, кусты и трава на атмосферных мирах — из пака Kenney, а вот
где они растут и как расставлены, считает игра (см. [README.md](README.md),
раздел «Жизнь на грунте»).

```
npm run nature                # пересобрать растительность
node tools/nature.mjs --list  # что есть в паке (329 моделей)
node tools/nature.mjs --clean # удалить скачанный пак
```

Перегон ([tools/nature.mjs](tools/nature.mjs)) отличается от остальных
двумя вещами.

Размер нормируется **по высоте**, а не по наибольшему габариту: растение
заказывают высотой («сосна двенадцать метров»), а у раскидистого куста
наибольший габарит — ширина, и нормировка по ней дала бы кусты вдвое
ниже заказанных.

Цвет лежит **ролями**: кора, листва, трава, цветок. Красит растение мир,
на котором оно выросло ([js/gl/flora.js](js/gl/flora.js), `tintOf`), а не
пак. Причина не в том, что авторская палитра мультяшная (листва в ней
бирюзовая, кора лососевая), хотя и в этом тоже: растения чужой планеты
не обязаны быть земной зеленью, и цвет им должен задавать грунт, на
котором они стоят. Геометрия при этом авторская, до единой вершины.

## Детали станций

Корпуса станций — свои: в них щель порта на оси вращения, плоскость
створа и тело столкновения, и всё это игра, а не украшение (см.
[README.md](README.md), раздел «Станции»). А навешанное на корпус —
тарелки связи, энергоблоки, баки, фермы, турели — взято готовым из пака
Kenney.

Пак удобен тем, что в нём НЕТ текстур: цвет лежит в материалах (`Kd` в
`.mtl`), а движок и так красит по грани. Перегон получается без потерь —
не усреднение картинки, а тот самый цвет, который задал автор.

```
npm run station                # пересобрать детали
node tools/station.mjs --list  # что есть в паке (150 моделей)
node tools/station.mjs --clean # удалить скачанный пак
```

Конвертер ([tools/station.mjs](tools/station.mjs)) сам скачивает пак и
приводит каждую деталь к общему виду: центр по X и Z, низ на нуле,
наибольший размер ровно 1000. Размер в километрах задаётся уже на месте
установки, поэтому одна и та же ферма идёт и на мачту «Орбиса», и в
обвязку створа. Результат — [js/models/station.parts.js](js/models/station.parts.js).

## Здания города

Планировка наземного города — своя: в ней посадочные площадки, габарит и
тела столкновения, то есть игра, а не вид (см. [README.md](README.md),
раздел «Наземный город»). А сами здания взяты готовыми из двух паков
Kenney: кварталы и башни — из городского, космопорт и техника — из
космического, того же, что у деталей станций.

Городской пак устроен иначе космического: текстура в нём одна на всё,
общий атлас, и цвет каждой грани снимается выборкой по её UV — той же
дорогой, что и у корабельной модели. Заодно оттуда берётся свечение:
стекло в атласе — единственная синяя колонка палитры, и по ней опознаются
окна, которые ночью светятся.

```
npm run city                # пересобрать детали города
node tools/city.mjs --list  # что есть в обоих паках
node tools/city.mjs --clean # удалить скачанные паки
```

Результат — [js/models/city.parts.js](js/models/city.parts.js): 28
деталей, 23 тысячи граней. Цвета сложены в палитру детали и огрублены до
шага в 3% яркости — в атласе каждый материал нарисован растяжкой, и
соседние грани стены снимают с неё десятки оттенков, различить которые
нельзя ничем, а файл они удваивают.
